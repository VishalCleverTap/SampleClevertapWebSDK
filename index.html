Campaign triggers

Each button records Engagement Event with its own Channel value. Target that event in a campaign to see it here.

  • For web push notification campaigns.

    Channel: "Web Push"

  • For web pop-up campaigns.

    Channel: "Web Pop-Up"

  • For exit-intent campaigns.

    Channel: "Web Exit Intent"

  • For Web Inbox messages, which open from Inbox at the top of the page. Also asks for your location.

    Channel: "Web Inbox"
